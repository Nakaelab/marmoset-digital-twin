AWS CLI Downloader

Select a dataset category below to copy the AWS CLI command. Use this command in your terminal to download files securely and quickly without browser limits.

aws s3 cp s3://digitaltwin-marmoset/3D_marmoset_body_data/CT_scan_data/ . --recursive --no-sign-request
AWS CLI Install Guide
  • Windows
  • macOS
  • Linux

Run the installer command in PowerShell:

msiexec.exe /i https://awscli.amazonaws.com/AWSCLIV2.msi

Download and run the installer:

curl "https://awscli.amazonaws.com/AWSCLIV2.pkg" -o "AWSCLIV2.pkg"
sudo installer -pkg AWSCLIV2.pkg -target /

Extract and run installation scripts:

curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
